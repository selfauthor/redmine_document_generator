# Конфигурация плагина

Плагин имеет единственный настраиваемый параметр, который доступен в разделе **Администрирование -> Плагины -> Redmine Document Generator -> Настроить**.

## Срок хранения сгенерированных документов (retention_hours)
- **Описание**: Определяет, сколько часов результаты генерации (файлы документов и ZIP-архивы) хранятся на сервере перед автоматическим удалением.
- **Значение по умолчанию**: `24` (часа).
- **Допустимые значения**: любое целое положительное число (минимум 1).
- **Как это работает**: При каждом открытии диалога генерации плагин проверяет директорию `tmp/document_generator` и удаляет все папки результатов, время последней модификации которых старше указанного количества часов. Это предотвращает бесконтрольный рост занимаемого дискового пространства.
