# Техническая документация Redmine Document Generator

## Архитектура
Плагин построен вокруг модуля `DocumentGenerator`, который инкапсулирует логику сбора данных, обработки шаблонов и генерации файлов.

### Основные компоненты
1. **`DocumentGenerator::TemplateProcessor`** (`app/models/document_generator/template_processor.rb`)
   - Центральный класс для парсинга и подстановки значений в шаблоны.
   - Использует `Nokogiri` для прямой модификации XML-содержимого архивов `.docx`/`.xlsx`.
   - Реализует стратегию обработки ошибок: `abort` (прерывание), `skip_field` (пропуск поля), `skip_record` (пропуск записи).

2. **Нормализация XML (`normalize_xml_nodes`)**
   - Word и Excel часто разбивают текст на несколько узлов `<w:t>` или `<t>` внутри одного прогона `<w:r>`.
   - Метод автоматически объединяет разбитые маркеры `<% ... %>` в один узел и разделяет узлы, содержащие смесь маркеров и обычного текста, сохраняя при этом исходное форматирование (`w:rPr`).

3. **Обработка архивов (`process_archive`)**
   - Использует `Zip::File` для безопасного извлечения, модификации целевых XML-файлов (например, `word/document.xml` или `xl/worksheets/sheet1.xml`) и обратной упаковки без повреждения служебных файлов архива.

## Хуки и интеграция
- Плагин расширяет стандартный экспорт списков задач через хуки контроллеров Redmine.
- Контекст данных формируется в `ContextBuilder` (не показан в фрагменте, но предполагается архитектурой), который подготавливает хэши с ключами в нижнем регистре для регистронезависимого поиска полей.

## Правила разработки
- Все файлы `.rb` начинаются с `# frozen_string_literal: true`.
- Комментарии в коде пишутся исключительно на русском языке.
- Все пользовательские сообщения локализуются через `I18n.t` и хранятся в `config/locales/`.
