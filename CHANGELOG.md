# Changelog

## [1.0.0] - 2026-10-26

### Добавлено
- Генерация документов Word (.docx) и Excel (.xlsx) на основе пользовательских шаблонов.
- Поддержка маркеров шаблона `<%...%>` для стандартных и пользовательских полей задач.
- Работа с вложенными сущностями: родительские задачи (`Parent`), подзадачи (`Subtask`), наблюдатели (`Watcher`) и связи (`Relation`).
- Фильтрация связей по типу (например, `<%BEGIN_RELATIONS:blocks%>`).
- Условная логика в шаблонах: блоки `<%IF(...) %>`, `<%ELSE%>`, `<%END%>`, включая специальную проверку на пустоту коллекций (`NOT Subtasks`, `NOT Watchers`, `NOT Relations`).
- Группировка данных (до 2 уровней вложенности) с заголовками и подвалами групп (`GROUP_BY`, `GROUP_HEADER`, `GROUP_FOOTER`).
- Агрегатные функции: `sum`, `avg`, `min`, `max` для текущей группы и `total_*` для всей выборки.
- Функции форматирования значений: `date`, `now`, `upper`, `lower`, `capitalize`, `truncate`, `strip_html`, `nl2br`, `replace`, `number`, `default`, `length`, `concat`.
- Вывод метаданных выгрузки: дата, пользователь, имя проекта, имя запроса, описание фильтров.
- Два режима экспорта: объединенный документ или отдельные файлы для каждой задачи (в ZIP-архиве).
- Выбор формата описания задачи: исходный текст или HTML-форматирование Redmine (только для Word).
- Гибкая стратегия обработки ошибок шаблона: прерывание, пропуск поля или пропуск всей записи.
- Индикатор прогресса генерации с фоновым обновлением статуса (heartbeat).
- Автоматическая очистка устаревших файлов результатов и снимков списков задач.
- Автоматическая нормализация разбитых XML-узлов в шаблонах Word/Excel для надежного распознавания маркеров.
